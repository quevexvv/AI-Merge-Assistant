# Локальный запуск: состояние интеграции

Снимок находится в работе. Сквозной запуск с GitHub, очередью, sandbox и
реальным выполнением тестов ещё не подтверждён. Не используйте его для
автоматического мержа или развёртывания на сервере.

## Демонстрация интерфейса

Нужны Node.js 24 и доступ к npm registry. Из корня репозитория:

```sh
cd frontend
npm ci
npm run dev:mock
```

Откройте адрес, который напечатает Vite. В этом режиме ответы возвращают
локальные моки; результат не является реальным прогоном тестов или мержа.
Проверки интерфейса запускаются командой `npm run check`.

## Backend и инфраструктура

Текущий Compose не готов к запуску как завершённый продукт: начальная миграция
пуста, постановка задач не использует Celery как очередь, а сквозная интеграция
с runner и sandbox отсутствует. Реальный GitHub-порт пока не подключён и
отвечает ошибкой, если не включён демонстрационный режим.
Перед общим запуском необходимо устранить эти проблемы и проверить миграции и
полный поток на отдельном тестовом окружении. Секреты задаются вне репозитория.

Для проверки конфигурации Compose задайте `POSTGRES_PASSWORD` в окружении;
он обязателен и должен состоять из символов, допустимых без кодирования в URL.
Команда `docker compose config -q` проверяет конфигурацию без запуска стека.
